# requiem.exe — итоговая V2

Основная версия для урока. V1 и V3 сохранены отдельно.

Исправлены вертикальные срезы волос и рук: спрайты показываются целиком с прежней высотой. Четыре героини перемещаются по очереди влево на передний план; их траектории учитывают края экрана. Размер персонажей заставки привязан к высоте сцены. Информационная плашка не закрывает лица в финальном обсуждении. Котики и смайлики повторно вырезаны из оригинальных листов. Титры и повторный запуск показывают затемнённый класс.

Звук: мягкая панорама окружения и действий без HRTF, задержек расширения и инверсии полярности. Голоса остаются в центре. Для проблемного стереофайла book-close при декодировании используется более сильный канал; длительность не меняется. Музыка сохранена.

Стартовые настройки: общая 85%, музыка 53%, эффекты 55%, голоса 45% (шкала голосов 0–150%). Новый профиль применяется один раз, затем сохраняются ваши изменения.

## Показ
Распакуйте Requiem-V2-project.rar и откройте index.html в Chrome/Edge. Интернет не нужен. Enter/пробел — продолжить, повторное нажатие ускоряет текущую анимацию. В опросах клавиши 1–4 соответствуют А/Б/В/Г. На телефоне — касания.

## GitHub Pages
Распакуйте Requiem-V2-github.rar. Загрузите его содержимое в корень репозитория: index.html, все CSS/JS и папку assets с сохранением вложенности. Сам RAR загружать вместо сайта не нужно. Settings → Pages → Deploy from a branch → main → /(root) → Save. Для публикации используйте эту модульную версию; музыка в ней загружается отдельно.
